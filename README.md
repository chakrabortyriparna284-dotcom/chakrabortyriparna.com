### 💥 Mission 01: [VoltTech — Electronic Product Store](https://github.com/chakrabortyriparna284-dotcom/electronic-product-store)
> **Role:** Full-Stack MERN E-Commerce Storefront (Capstone Project)  
> **Repository:** [`chakrabortyriparna284-dotcom/electronic-product-store`](https://github.com/chakrabortyriparna284-dotcom/electronic-product-store)  
> **Status:** ★ 2 Stars • [Live Demo on Vercel ↗](https://electronic-product-store.vercel.app)

* **Smart Catalog & Inventory:** Multi-category filtering (*Laptops, Smartphones, Audio, Wearables, Accessories*), instant search, stock status badges, star review counters.
* **Cart & Checkout Logic:** Client-side LocalStorage cart synced with MongoDB order persistence, automatic 8% tax calculation, free shipping thresholds, and custom unique Order IDs.
* **Authentication & Safety:** User registration and sign-in with `bcryptjs` password hashing and JWT token-protected REST endpoints. Includes a **1-Click Demo Login** for rapid evaluation.
* **Architecture Structure:** Decoupled `client/` (React) and `server/` (Express & MongoDB) with `SPEC.md`, Architecture Decision Records (ADRs), and a pre-configured database seed script (`npm run seed`) loading 8 production tech hardware products.

## 🧪 Local Deployment & WebGL Shader

To run this GTA VI themed interactive portfolio locally:

```bash
# Clone the repository
git clone https://github.com/chakrabortyriparna284-dotcom/gta6-portfolio-github.git

# Enter the directory
cd gta6-portfolio-github

# Serve with any static web server
npx serve .
# or
python -m http.server 8000
```

Open `http://localhost:8000` (or `http://localhost:3000`) in your browser.
